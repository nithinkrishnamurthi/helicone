# Add a "Docs" link to the main navigation

Add a "Docs" link to the top navigation / sidebar of the signed-in
Helicone self-host dashboard that opens https://docs.helicone.ai in a
new tab.

## How to reach the app

Helicone runs on http://localhost:3000. First-time use requires signing
up a new account.

## Acceptance

- A "Docs" link is visible in the main nav on any signed-in page.
- Clicking it opens https://docs.helicone.ai in a new tab
  (target=_blank, rel=noopener).
- No other nav items are moved or removed.
